为什么不能只在浏览器里抓？

        
浏览器会受到跨域限制，而且现代分享页的数据可能嵌在 React Server Components 数据中，因此提取工作放在服务端完成。

      

      

        
失败时怎么办？

        
如果链接被删除、需要登录、属于受限工作区，或页面结构发生变化，页面会显示明确错误。你仍可打开原分享页手动复制。

      

      

        
隐私说明

        
本项目不需要 ChatGPT 账号、Cookie 或 API Key，也不会尝试读取私人聊天。部署者可自行增加日志或存储策略。
